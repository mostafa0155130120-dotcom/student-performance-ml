# مشروع تصنيف الأداء الدراسي

مشروع متكامل لتحليل بيانات xAPI-Edu-Data، ومقارنة نماذج تصنيف متعددة، ثم تشغيل واجهة تفاعلية للتقدير الفردي أو لملف CSV.

## تشغيل المشروع

يتطلب Python 3.11 أو أحدث.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python train.py
streamlit run app.py
```

افتح العنوان المحلي الذي يعرضه Streamlit. يعيد `train.py` تدريب النماذج ويختار الأفضل وفق متوسط **macro F1** في تحقق متقاطع طبقي متكرر، ثم يقيسه مرة واحدة على مجموعة اختبار منفصلة. تُحفظ النماذج والتقارير داخل `artifacts/`.

لتشغيل الدفتر التفاعلي ثبّت إضافات التطوير أيضًا: `pip install -r requirements-dev.txt`.

## ما الذي أُضيف؟

- تجهيز مسبق داخل pipeline: تعويض القيم المفقودة، توحيد المقاييس الرقمية، وترميز الفئات مع دعم الفئات الجديدة.
- مقارنة Logistic Regression وRandom Forest وExtra Trees وRBF SVM.
- تقييم متعدد المقاييس مع مقارنة بخط أساس بسيط، ومصفوفة التباس وتقرير لكل فئة.
- معايرة sigmoid لدرجات الفئات باستخدام طيات من بيانات التدريب، مع قياس Brier على الاختبار.
- تحليل وصفي للفروق حسب النوع في مجموعة الاختبار؛ النوع والجنسية ومكان الميلاد لا تدخل في التنبؤ.
- أهمية سمات تقديرية عبر permutation importance.
- واجهة ثنائية اللغة: الإنجليزية افتراضيًا ومحاذاة يسارًا، مع نسخة عربية RTL على اليمين؛ ويمكن التبديل بين اللغتين. العنوان يظهر باللغتين جنبًا إلى جنب.
- تقدير طالب فردي أو رفع CSV وتنزيل النتائج، مع أفكار متابعة داعمة.
- تغليف Docker وتجهيز النشر على خدمة تستضيف تطبيق Streamlit.

## ملفات المشروع

- `student_performance_ml.ipynb`: نسخة مطوّرة من الـ notebook تشمل EDA والتدريب وقراءة النتائج.
- `data/xAPI-Edu-Data.csv`: نسخة المصدر العام (480 سجلًا). الـ notebook الأصلي أشار إلى ملف تنظيف محلي من 478 سجلًا، لكنه لم يكن مرفقًا؛ لذلك لا يمكن إعادة إنتاج التنظيف نفسه بدقة. يستطيع المشروع التدريب على نسخة المستخدم ذات 478 صفًا باستخدام `python train.py --data مسار_الملف.csv`.
- `train.py` و`model.py`: التدريب وخط المعالجة المشترك.
- `app.py`: الواجهة التفاعلية.
- `artifacts/`: النموذج والتقارير التي ينتجها التدريب.

## نتيجة التشغيل المرفقة

اختير Random Forest بمتوسط macro F1 قدره **0.770** عبر التحقق المتقاطع. على مجموعة الاختبار المنفصلة (96 سجلًا)، حقق macro F1 قدره **0.749** وbalanced accuracy قدره **0.748**؛ خط الأساس الذي يتوقع دائمًا الفئة الأكثر شيوعًا حقق دقة **0.438**. هذه نتيجة أولية على عينة صغيرة وليست ضمانًا للأداء خارجها.

## النشر على Streamlit Community Cloud

المشروع مُعدّ للنشر مباشرة من GitHub باستخدام Streamlit Community Cloud، بدون إعداد Docker أو Render:

1. ارفع مجلد المشروع إلى مستودع GitHub على الفرع `main`.
2. اربط حساب GitHub بمنصة Streamlit Community Cloud. إذا كان المستودع خاصًا، فعّل وصول Streamlit إلى المستودعات الخاصة من إعدادات الحساب المرتبط.
3. أنشئ تطبيقًا جديدًا، واختر المستودع والفرع `main` وملف التشغيل `app.py`.
4. احتفظ بخصوصية المستودع والتطبيق ما لم ترغب صراحةً في نشرهما للعموم.

يحتوي المستودع على `requirements.txt` و`artifacts/model.joblib` والبيانات التي تحتاجها الواجهة. بعد النشر، تُحدّث Community Cloud التطبيق تلقائيًا عند دفع تغييرات جديدة إلى GitHub.

## المصدر والقيود

البيانات هي **Students' Academic Performance Dataset (xAPI-Edu-Data)**. المصدر الأصلي على [Kaggle](https://www.kaggle.com/datasets/aljarah/xAPI-Edu-Data)، والنسخة الموجودة هنا من [مرآة GitHub](https://github.com/basilatawneh/Students-Academic-Performance-Dataset-xAPI-Edu-Data-/blob/master/xAPI-Edu-Data.csv). راجع صفحة المصدر قبل إعادة التوزيع العام للتأكد من شروط الاستخدام والإسناد.

العينة صغيرة ومحدودة بسياق جمع واحد؛ أرقام الاختبار تقدير أولي وقد تختلف كثيرًا عند الانتقال إلى مدرسة أخرى. درجة النموذج معايرة داخليًا بطريقة sigmoid، لكن حجم العينة لا يسمح باعتبارها احتمالًا موثوقًا. التوقع ليس تشخيصًا ولا دليلًا سببيًا؛ ينبغي استخدامه لفتح مراجعة بشرية داعمة فقط، وعدم اتخاذ قرارات آلية بحق الطلاب.
